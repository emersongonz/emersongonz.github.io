---

## 🚀 Cómo Visualizar el Proyecto Localmente

1. **Opción Directa:**
   - Haz doble clic sobre el archivo `index.html` para abrirlo en cualquier navegador web (Google Chrome, Edge, Firefox, Brave).

2. **Opción con Servidor Local (Python):**
   - Abre PowerShell o una terminal en esta carpeta y ejecuta:
     ```bash
     python -m http.server 8080
     ```
   - Abre tu navegador en `http://localhost:8080`

## 🌐 Cómo Publicar en GitHub Pages (Gratis)

Para tener tu enlace público como `https://tu-usuario.github.io`:
1. Crea una cuenta en [GitHub.com](https://github.com) (si aún no tienes una).
2. Crea un nuevo repositorio público con el nombre:
   `tu-usuario.github.io` (sustituyendo `tu-usuario` por tu nombre de usuario en GitHub).
3. Sube todos los archivos de esta carpeta (`index.html`, `foto.jpeg`, los archivos `.jpg` y `.pdf`) al repositorio.
4. En la configuración del repositorio (**Settings** > **Pages**), asegúrate de que la rama `main` esté seleccionada en la raíz `/ (root)`.
5. ¡Listo! Tu portafolio estará disponible en internet para cualquier cliente o reclutador.

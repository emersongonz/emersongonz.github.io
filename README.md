* **URL de despliegue sugerida:** `https://emersongonz.github.io`

---

## 🚀 Cómo Visualizar el Proyecto Localmente

1. **Opción Directa:**
   - Haz doble clic sobre el archivo `index.html` para abrirlo en cualquier navegador web (Chrome, Edge, Firefox, Brave).

2. **Opción con Servidor Local (Python):**
   - Ejecuta en la terminal de esta carpeta:
     ```bash
     python -m http.server 8080
     ```
   - Abre en tu navegador: `http://localhost:8080`

---

## 🌐 Publicar en GitHub Pages (`emersongonz.github.io`)

Tu repositorio local de Git ya ha sido inicializado y tiene el commit inicial listo. Para publicarlo en tu cuenta:

1. Ve a **GitHub** y crea un nuevo repositorio público llamado exactamente:
   ```text
   emersongonz.github.io
   ```
   *(Deja desmarcadas las opciones de "Add a README file" y ".gitignore")*

2. En tu terminal (PowerShell), vincula el repositorio remoto y sube los archivos:
   ```powershell
   & "C:\Program Files\Git\cmd\git.exe" remote add origin https://github.com/emersongonz/emersongonz.github.io.git
   & "C:\Program Files\Git\cmd\git.exe" push -u origin main
   ```

3. **¡Listo!** En aproximadamente 1 o 2 minutos tu sitio estará en línea de forma pública y gratuita en:
   **`https://emersongonz.github.io/`**
